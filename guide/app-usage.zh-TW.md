# App 使用指南（視窗 + 桌寵模式，按鈕功能版）

## 1）使用前
- 後端需先啟動：`uv run run_server.py`
- 啟動 Electron App
- 確認 WebSocket 已連線

## 2）視窗模式（按鈕與功能）
視窗模式功能基本等同 Web 模式，外加桌面應用控制。

### 側邊欄控制
- **設定按鈕**：開啟設定抽屜
- **歷史紀錄**：開啟歷史對話
- **新建對話**：建立新聊天
- **側欄收合鍵**：收合/展開側邊欄

### 主畫面控制
- **連線狀態/重連圖示**：顯示 WS 狀態，斷線可重連
- **Live2D 區域**：可拖曳；可配置點擊互動

### 底部控制
- **麥克風按鈕**：開/關語音輸入
- **打斷按鈕**：立即停止 AI 目前發話
- **文字輸入框 + 送出**：以文字與 AI 對話
- **底欄收合鍵**：收合/展開底部控制欄

### 設定抽屜分頁
- **General**：連線、背景、字幕、角色預設
- **Live2D**：互動與縮放設定
- **ASR**：語音閾值與自動麥克風
- **TTS**：語音合成相關設定（若有）
- **Agent**：AI 主動說話設定
- **About**：專案/應用資訊

## 3）桌寵模式（按鈕與選單）
桌寵模式支援透明背景與全局置頂。

### 模型右鍵選單
- **麥克風開/關**
- **打斷目前對話**
- **開啟/關閉縮放**
- **顯示/隱藏輸入框與字幕**
- **切換模式（桌寵/視窗）**
- **切換角色**
- **隱藏應用 / 退出應用**

### 輸入框與字幕浮動區
- 可拖曳位置
- 可顯示/隱藏
- 內含麥克風、打斷、文字輸入

## 4）系統托盤功能
- 顯示/隱藏視窗
- 切換模式
- 快速退出

## 5）建議使用流程
1. 先啟動後端
2. 開 App 並確認連線
3. 選擇視窗或桌寵模式
4. 用麥克風或文字對話
5. 需要時使用打斷
6. 透過歷史紀錄回看/切換對話
