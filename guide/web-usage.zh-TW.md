# Web 使用指南

## 1）開啟 Web 介面
- 啟動後端：`uv run run_server.py`
- 開啟：`http://localhost:12393`

## 2）主畫面結構
- 側邊欄：設定、歷史紀錄、新建對話
- 主區域：Live2D、背景、字幕、連線狀態
- 底部欄：AI 狀態、麥克風開關、打斷按鈕、文字輸入框

## 3）設定總覽
### General
- 語言（若有）
- 背景圖／自訂 URL／攝影機背景
- 角色預設
- WebSocket 位址
- Base URL
- 字幕開關

### Live2D
- 滑鼠互動開關
- 縮放開關（滾輪/雙指）

### ASR
- 自動麥克風控制
- 語音偵測閾值

### Agent
- AI 主動說話開關
- 閒置多久後主動說話

## 4）對話方式
- 語音輸入（需麥克風權限）
- 文字輸入
- AI 主動說話（需在設定開啟）

## 5）打斷邏輯
可透過以下方式打斷：
- 按打斷按鈕
- AI 說話時你直接說話（麥克風需開啟）
- AI 說話時送出新訊息

## 6）聊天紀錄
- 可滾動查看目前對話
- 歷史抽屜可載入/刪除既有對話

## 7）Live2D 操作
- 拖曳移動
- 滾輪/雙指縮放
- 視線跟隨與點擊動作（取決於設定）

## 8）遠端使用
若在非 localhost 裝置使用麥克風/攝影機/錄屏，需配置 HTTPS。
